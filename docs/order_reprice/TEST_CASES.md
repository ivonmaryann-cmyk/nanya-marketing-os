# 订单改价测试案例

## 静态 smoke test

运行：

```powershell
python tests\smoke_order_reprice.py
```

预期：

- `order_reprice_service.py` 可导入。
- PP 识别正确。
- PP 长度解析正确。
- RC 区间匹配正确。
- 布种多值匹配正确。
- 厚度多值匹配正确。
- 功能三 PP 价格可按长度换算。

## block1：430 匹配

样例目录建议：

```text
D:\桌面\胜宏\功能一原始数据
```

预期：

- 精确项次可匹配。
- 拆分项次如 `1 -> 101,102` 可输出厂内项次。
- 有歧义的拆分项次标记为歧义，不自动匹配。

## block2：430 价格核对

样例目录建议：

```text
D:\桌面\胜宏\功能二原始数据
```

预期：

- `NY2170P:2116RC55%300M/R` 命中报价单价格 `5691`。
- `NY3170M2P` 可兜底命中高速报价中的 `NY3170M2`。
- `2313/3313` 可匹配任一布种。
- `64%-66%` 可匹配区间内 RC。
- `0.100/0.102` 可匹配任一厚度。

## block3：411 价格核对

样例目录建议：

```text
D:\桌面\胜宏\功能三原始数据
```

预期：

- PP 行按 `单价 × PP长度` 比对。
- `NY-P3P(C):1078RC66%300M/R` 可识别为 PP。
- 非 PP 行取 411 `单价`。
- 拆分匹配到 `101,102` 时只取一个价格，不累加。
