# 订单改价模块规格说明

## 模块定位

订单改价是平台中的批量 Excel 任务功能，使用现有任务队列、历史记录、下载、日志轮询机制，不单独新增数据库表。

## 功能入口

- feature key：`order_reprice`
- 页面路由：`GET /features/order-reprice`
- 任务提交路由：`POST /order-reprice/jobs`
- worker 分发：`python -m fangzheng_web_app.job_worker <job_id> order_reprice <employee_id>`

## 三块业务

### block1：430 匹配

输入：

- 客户明细
- 430 厂内明细

匹配字段：

- 客户：`采购订单号 + 项次 + 料件编号`
- 430 厂内：`客户订单 + 项次 + 客户产品编号`

输出 Sheet：

- `客户明细匹配结果`
- `厂内明细匹配结果`
- `匹配汇总`

### block2：430 价格核对

输入：

- 客户明细
- 430 厂内明细
- 一个或多个胜宏报价单

关键规则：

- PP 数量按长度换算：采购单位为卷时，`实际订单数量 = PP长度 × 采购量`。
- PP 报价支持产品型号别名，例如 `NY3170M2P` 可兜底匹配 `NY3170M2`。
- PP 布种支持多候选值，例如 `2313/3313`。
- RC 支持区间，例如 `64%-66%`、`0.64-0.66`。
- CCL 厚度支持多候选值，例如 `0.100/0.102`。

输出 Sheet：

- `客户价格核对结果`
- `匹配汇总`
- `报价未命中说明`

### block3：411 价格核对

输入：

- 客户改价明细
- 411 厂内明细

匹配字段：

- 客户：`采购订单号 + 项次 + 料件编号`
- 411 厂内：`客户单号 + 项次 + 客户产品编号`

关键规则：

- PP 价格使用 `411单价 × PP长度`。
- 非 PP 价格取 411 `单价`。
- 拆分匹配到多个厂内项次时，只按厂内项次排序取第一个可用价格，不累加。

输出 Sheet：

- `客户改价核对结果`
- `核对汇总`

## 页面结构

当前页面包含：

- 客户选择：胜宏可用，景旺/博敏待接入。
- 功能 Tab：`430匹配`、`430价格核对`、`411价格核对`。
- 左侧业务操作区，右侧 Live Console 日志区。
- 完成后展示统计卡片和结果下载入口。
