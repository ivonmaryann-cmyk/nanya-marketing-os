# 料号查询与异步创建闭环开发计划

## 1. 目标

建立可长期复用的“查询料号—创建中—外部回调携带结果—回填—录单”闭环。

- 查询命中时，自动回填产品编号（料号）和品名。
- 查询未命中时，显示“创建料号中”，等待外部系统主动回调。
- 回调直接带回料号、品名，系统直接回填，无需业务人员再次点击。
- 任一明细未完成料号时，禁止提交录单。

Mock 与真实接口共用同一套状态、数据表、页面展示和日志；真实接口上线时只替换传输配置、鉴权和报文映射。

## 2. 批量料号查询

### 输入

每条订单明细提交以下字段，并携带订单、模板、行号和查询关联号：

- 客户产品编号
- 客户规格
- 客户规格匹配

### 即时返回与页面处理

| 外部返回状态 | 平台处理 | 页面表现 |
| --- | --- | --- |
| 已找到 | 自动回填产品编号、品名 | 对应两列显示回填结果 |
| 创建料号中 | 保存外部创建任务号，并将接口原文“创建料号中”写入产品编号、品名 | 两个内容格直接显示“创建料号中”，不额外显示状态 |
| 查询失败 | 不改变模板字段，保存失败信息 | Excel 保持空白，错误仅在“接口交互”查看 |

所有自动回填需记录来源、接口调用号、回填前后值和时间；后续人工修改也要留痕。

## 3. 异步回调与直接回填

### 回调数据

外部系统创建完成后主动请求平台回调地址，至少传递：

- 查询关联号或外部创建任务号
- 订单/模板标识
- 明细行标识
- 创建完成状态

真实接口上线前，信息部需确定签名、Token 或 IP 白名单等回调鉴权方式。

### 回调处理

1. 校验回调身份和关联号。
2. 回调直接携带产品编号和品名。
3. 平台以回调内容覆盖“创建料号中”占位值，并保存接口交互记录。
4. 回调缺少料号或品名时拒绝处理并记录异常，等待对方重试。

业务人员无需再次点击批量料号查询。

## 4. 状态机

- 待查询 → 批量料号查询
- 已命中 → 已回填
- 创建料号中 → 等待外部回调携带料号和品名 → 已回填
- 查询失败 → 保留接口错误记录，等待人工再次发起查询

## 5. 页面与录单规则

### 内销录单模板

- 保持“下载 Excel、保存”顶部交互不变。
- 模板区右上保留“批量料号查询”和“提交录单”。
- 产品编号、品名列展示自动回填结果。
- 创建未完成的行显示“创建料号中”，不显示伪造料号。
- “流程记录、数据变更、接口交互”完整记录查询、回调和回填过程。

### 录单拦截

任一明细处于“创建料号中”或没有可用料号时，禁止提交录单，并提示：

> 存在未完成料号，请等待料号创建完成或补齐料号后再提交录单。

全部明细已回填，或由业务人员明确补齐必填料号信息后，才允许提交录单。

## 6. Mock 方案

Mock 必须模拟真实异步链路，不能只写日志：

1. 第 1 行直接命中，自动回填 Mock 产品编号和品名。
2. 第 2 行返回“创建料号中”。
3. Mock 不模拟料号创建完成或回调；该环节由真实外部系统后续联调验证。
4. 第 3 行可保留失败返回，仅在接口交互记录中查看，不污染 Excel 内容格。

真实回调必须直接复用平台回调服务，不能绕过流程修改数据库或页面。

## 7. 数据与安全

新增或扩展以下持久化信息：

- 明细料号状态、状态更新时间和回填来源。
- 查询关联号、外部创建任务号、回调原始状态。
- 每次查询、回调的请求/响应、耗时和配置版本。
- 回调日志、校验结果和异常信息。
- 产品编号、品名自动回填及人工覆盖事件。

接口日志保留脱敏业务数据；鉴权信息和回调密钥仅管理员可维护，业务人员不可见。

## 8. 开发阶段与验收

### 阶段一：状态与即时回填

- 增加明细料号状态、关联号和回填来源。
- 命中时回填产品编号、品名。
- 未命中时显示“创建料号中”。

验收：一个订单可同时有已回填和创建中的明细，字段不会被错误覆盖。

### 阶段二：真实异步回调准备

- 建立回调入口和关联校验。
- 回调直接接收料号、品名并回填。
- Mock 仅保留“创建料号中”返回，不伪造外部回调。

验收：真实回调到达后无需业务人员再次查询，即可直接回填。

### 阶段三：录单拦截与 Mock 录单

- 未完成料号时拦截提交录单。
- 全部完成后允许 Mock 录单。

验收：未完成时无法提交；完成后产生 Mock 单号和交互记录。

### 阶段四：真实接口联调

- 接入信息部提供的批量查询、创建回调和录单报文。
- 接入鉴权、回调签名校验和异常重试。
- 保持 Mock 与真实接口使用同一业务状态机。

验收：只替换传输层配置，不重做订单状态、回填、记录和拦截规则。

## 9. 信息部待提供

1. 批量料号查询的完整请求、响应和错误码。
2. 未命中创建料号时的状态字段、任务号和完成语义。
3. 创建完成回调的 URL、字段、签名/鉴权和重试规则。
4. 回调中产品编号、品名、关联号的字段名及传递方式。
5. 内销录单接口的请求、响应、幂等键、失败重试和取消规则。
