# 在途核对规则

## 功能定位

“在途核对”用于核对客户在途数据。用户上传一个 Excel 文件，文件内必须包含 `厂内明细` 和 `客户明细` 两张 Sheet。系统清洗两张表后，按严格匹配键做一对一核对，并输出数量、品名、日期和待出货明细结果。

## 输入文件

- 文件格式：`.xlsx`、`.xlsm`、`.xls`。
- Sheet 要求：
  - `厂内明细`：对应系统数据。
  - `客户明细`：对应客户数据。
- 缺少任一 Sheet 时，任务失败并提示文件必须包含 `厂内明细` 和 `客户明细`。

## 系统数据清洗

系统数据来自 `厂内明细`。系统会自动识别表头行，保留以下字段：

`预交货日`、`单别单号`、`项次`、`厂别`、`订单日期`、`客户编号`、`客户简称`、`所属集团公司`、`品号`、`品名`、`规格`、`双幅`、`订单数量`、`单位`、`数量`、`单位`、`客户单号`、`客户产品编号`、`客户规格`、`到货日期`

清洗删除规则按顺序执行：

1. 删除 `单别单号` 含 `341-` 或 `219-` 的行。
2. 删除 `订单数量` 为空或为 0 的行。
3. 删除 `厂别` 为空的行。

## 到货日期规则

系统数据会根据 `预交货日`、`厂别`、`客户简称` 生成 `到货日期`。

- `厂别 = N3` 且 `客户简称` 为 `无锡深南` 或 `南通深南`：`到货日期 = 预交货日`
- `厂别 = N3` 且 `客户简称 = 深南电路`：`到货日期 = 预交货日 + 2 天`
- `厂别 in N4/N5/N6` 且 `客户简称` 为 `无锡深南` 或 `南通深南`：`到货日期 = 预交货日 + 2 天`
- `厂别 in N4/N5/N6` 且 `客户简称 = 深南电路`：`到货日期 = 预交货日 + 1 天`
- 其他厂别/客户组合无法生成到货日期时，`到货日期` 为空。

日期兼容：

- 支持 Excel 日期、`YYYY-MM-DD`、`YYYY/MM/DD`、`YYYYMMDD`、含时间的日期文本。
- `.xls` 中的 Excel 日期序列号需要转为真实日期，例如 `46168.0` 应解析为 `2026-05-26`。
- 普通数量数字不应被当成日期。

## 客户数据清洗

客户数据来自 `客户明细`。关键字段包括：

`单据编号`、`物料编码`、`单据行号`、`订单承诺日期`、`物料数量`、`物料单位`、`物料说明`

数量规则：

- 默认使用客户表 `物料数量`。
- 当 `物料单位 = 卷` 时，从 `物料说明` 提取独立 PP 长度 token，并折算 `物料数量`。
- 支持长度 token 示例：`300M`、`200M`、`300M49I`。
- 禁止从型号中误提取长度，例如 `NHY3150MP`、`NY3170MP` 不得提取出 `3150M` 或 `3170M`。

## 匹配规则

匹配采用严格四字段一对一：

- 系统数据匹配键：`客户单号 + 客户产品编号 + 项次 + 到货日期`
- 客户数据匹配键：`单据编号 + 物料编码 + 单据行号 + 订单承诺日期`

匹配状态：

- `匹配成功`：双方匹配键唯一且互相找到。
- `未匹配`：对方没有对应唯一键。
- `本表匹配键重复`：本表同一匹配键出现多次。
- `对方匹配键重复`：对方同一匹配键出现多次。

重复键不强行匹配，避免误判。

## 数量判断

仅匹配成功行进行数量判断：

- 系统 `订单数量` 与客户折算后的 `物料数量` 一致：`正确`
- 不一致：`错误`
- 任一数量无法解析：`无法判断`

## 品名判断

系统数据 `品名` 不做转码，仅作为核对基准。

客户数据只对匹配成功行的 `物料说明` 做“物料说明转品名”：

- 覆铜板 / CCL：复用“营销自动化转码”的当前活动规则和转码引擎。
- PP / 半固化片：当前使用在途核对专用保守 helper；无法稳定生成内部品名时输出 `无法判断`。
- 非可识别物料说明：输出 `无法判断`。

品名判断：

- 转换后品名与系统 `品名` 规范化后一致：`正确`
- 不一致：`错误`
- 转换结果为空或 `无法判断`：`无法判断`

## 日期判断

`客户数据核对` Sheet 中新增：

- `系统到货日期`：匹配成功时回填系统数据 `到货日期`。
- `订单承诺日期(年月日)`：客户原始 `订单承诺日期` 标准化为 `yyyy-mm-dd`。
- `日期判断`：系统到货日期与客户订单承诺日期一致为 `正确`，不一致为 `错误`，任一日期无法解析为 `无法判断`。

未匹配或重复键行不做日期判断，不回填系统到货日期。

## 待出货明细规则

`待出货明细` 从 `系统数据核对` 中筛选，表头与 `系统数据核对` 完全一致。

筛选基准日：

- 取客户明细中最早可解析的 `订单承诺日期 - 1 天`。
- 如果客户明细没有任何可解析 `订单承诺日期`，回退为任务运行当天。

非周五基准日：

- `客户简称` 为 `无锡深南` 或 `南通深南`，且 `到货日期 = 基准日 + 1 天`。
- `客户简称 = 深南电路`，且 `到货日期 = 基准日 + 3 天`。

周五基准日：

- `客户简称` 为 `无锡深南` 或 `南通深南`，且 `到货日期 in [基准日+1, 基准日+2, 基准日+3]`。
- `客户简称 = 深南电路`，且 `到货日期 in [基准日+3, 基准日+4, 基准日+5]`。

## 输出结果

结果 Excel 输出 4 张 Sheet，顺序固定：

1. `核对汇总`
2. `系统数据核对`
3. `待出货明细`
4. `客户数据核对`

`系统数据核对`：

- 系统保留字段
- `客户物料数量`
- `匹配状态`
- `数量判断`

`待出货明细`：

- 与 `系统数据核对` 完全相同的列结构。

`客户数据核对`：

- 客户原始字段
- `品名` 插入在客户原始字段 `物料说明` 后
- 追加 `订单数量`、`数量判断`、`物料说明转品名`、`品名判断`、`系统到货日期`、`订单承诺日期(年月日)`、`日期判断`

`核对汇总` 包含清洗、匹配、数量、品名、日期、待出货明细行数和待出货筛选基准日等统计。
