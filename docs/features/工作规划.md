# 工作规划

## 业务目标

为当前登录工号提供个人私有待办管理能力，用于记录和规划日常工作事项。该功能不关联报价、转码、在途核对等 Excel 计算任务。

## 功能状态

已上线。

## 页面入口

- 功能中心卡片：工作规划
- 左侧导航：工作规划
- 路由：`/tasks`

## 核心能力

- 新建、编辑、删除个人任务
- 完成任务后自动归档
- 已归档任务可恢复
- 支持自定义任务分类
- 支持任务标题、分类、分类简称标签、优先级、进展、截止日期、任务描述
- 默认按自定义任务分类分组展示
- 支持快捷筛选：全部任务、今天、逾期、进行中、已归档
- 支持手动保存当前任务清单，并从最近一次保存恢复
- 支持同一任务分类内拖拽排序，排序结果会写入数据库
- 支持中间列表按任务分类、项目优先级、任务进展切换分组
- 支持舒适、标准、紧凑三档任务行密度，本机浏览器记忆
- 支持左侧筛选栏和右侧创建/编辑栏宽度拖拽调整，本机浏览器记忆
- 支持按项目优先级分组时，同一优先级组内拖拽排序

## 数据表

新增独立 SQLite 表：

- `task_categories`：当前工号的自定义任务分类
- `personal_tasks`：当前工号的个人任务

任务数据按 `employee_id` 隔离，每个用户只查看和维护自己的任务。

## 默认分类

用户首次进入工作规划时，自动创建：

- 人力资源任务
- AI开发任务
- 其它业务任务

后续可自行新增、改名、删除分类。删除分类时，该分类下原任务会移动到未分类。

## 任务清单备份

页面提供：

- 保存当前清单
- 恢复上次清单

当前本地备份根目录：

```text
D:\Carson\tmp\work_planning_backups
```

每个工号独立保存：

```text
D:\Carson\tmp\work_planning_backups\<工号>\latest.json
```

例如工号 `23406`：

```text
D:\Carson\tmp\work_planning_backups\23406\latest.json
```

备份内容包含当前用户的任务分类、分类简称、未归档任务、已归档任务、优先级、进展、截止日期、描述和分类归属。恢复时会覆盖当前用户在数据库中的工作规划数据，再按备份文件重建分类和任务。

## 注意事项

- 不复用 `jobs` 表，避免和 Excel 后台任务混淆。
- 不新增外部依赖。
- 不修改账号、规则、计算引擎和文件存储逻辑。
- 当前版本不包含到期提醒、团队协作、子任务和重复任务。
- 当前备份为本地固定目录 JSON 快照；如果要跨服务器/本地恢复，需要复制对应 `latest.json`。
- 拖拽排序在“按任务分类”和“按项目优先级”分组模式下启用，仅允许同组内排序，避免跨组拖动造成字段修改歧义。
