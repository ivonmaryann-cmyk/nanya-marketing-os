# 全平台迁移逐表映射清单（2026-08-27）

> 对应计划：`全平台统一PostgreSQL实际迁移执行计划.md` 的 P1.2。
> 操作性质：本清单来自只读盘点；不代表已建表或已迁移。
> 目标：`nanya-automation-dev` 的单一 PostgreSQL 开发库。

## 使用规则

- “来源行数”是本次盘点快照，P3 冻结后必须重新统计，并以最终快照为准。
- `迁移` 保留来源主键，采用幂等 Upsert；`初始化` 不复制旧记录，由目标库 Schema/新运行时生成。
- 邮件、客户、订单、料号和接口域只从本机 Docker PostgreSQL 读取；即使 SQLite 有同名表也不得再复制。
- 用户、设置、转码、任务与反馈域只从 SQLite 读取。
- 本清单仅能在 P0.3 权限检查通过、P3 备份完成后用于 P4/P5 执行。

## P4/P5 实施顺序

1. 身份与全局配置；
2. 转码、共享任务、工作规划；
3. 自动化规则与客户；
4. 邮件账号、抓取任务、邮件、附件索引与附件文本；
5. 订单案例、录单模板、料号任务、接口配置与所有业务审计记录；
6. 校准序列、生成新库 Schema 版本与运行状态；
7. P6 逐表行数、主键集、标准化哈希、关联与文件索引对账。
