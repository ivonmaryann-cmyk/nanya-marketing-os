# 订单邮件自动化第三阶段切换、回滚与观察开发报告

## 范围和结论

本阶段仅完成DB-16至DB-18所需的切换准备、变更捕获、回滚回放和稳定观察工具。未执行生产切换，未开启PostgreSQL变更捕获，未回放生产数据，未开始正式7至14天观察，未删除或修改SQLite历史业务数据。

DB-16至DB-18均保持“待验证”。`AUTOMATION_DATABASE_BACKEND`仍为SQLite，`AUTOMATION_POSTGRESQL_READ_WRITE_ENABLED`仍应保持关闭。

## DB-16 切换准备

- 切换准备必须先通过DB-15全部准入条件。
- 强制要求切换负责人、复核负责人、回滚负责人为三个不同的实名人员，并填写维护窗口。
- 切换前确认Outbox为0，创建SQLite一致性备份并记录SHA256。
- 使用备份与PostgreSQL执行20表全量核对，检查迁移版本和变更捕获默认关闭。
- 核对后再次检查Outbox，防止维护窗口内新增写入越过最终快照。
- 生成切换清单和一次性授权令牌。启用变更捕获仍不会自动修改应用后端环境变量。

## DB-17 回滚能力

- `0003_cutover_rollback.sql`为20张PostgreSQL业务表建立变更捕获触发器，默认`capture_changes=false`。
- 只有通过切换清单授权后才能开启捕获。
- 变更日志保存在受数据库权限保护的辅助表中，不写入普通应用日志。
- 回放要求SQLite备份文件存在且SHA256一致，并要求固定确认词。
- 回放按PostgreSQL变更ID顺序幂等写回SQLite，支持复合主键、插入、更新和删除。
- 回放期间抑制SQLite Outbox，避免数据再次同步回PostgreSQL形成循环。
- SQLite批次提交成功后才标记PostgreSQL日志已回放；中途崩溃可以重复执行。
- 所有变更回放完毕后自动关闭PostgreSQL变更捕获。

## DB-18 稳定观察

- 采集PostgreSQL连接数、事务提交/回滚、死锁、临时文件、数据库大小和业务表数量。
- 同时记录Outbox积压、7天影子差异和未回放变更日志数量。
- 每份报告默认`health_ok=false`，必须由负责人复核后才能改为通过。
- 观察门禁要求7至14个不同日期的报告全部人工通过、Outbox为0且影子差异为0。
- SQLite原表在切换后至少只读保留30天，本阶段没有删除能力。

## 准备命令

以下命令当前不得针对生产执行。所有准入证据齐全后，先生成切换清单：

```powershell
python -m fangzheng_web_app.automation_migration prepare-cutover --sqlite storage/app.db --evidence config/automation_preflight.local.json --backup-dir backups/automation-cutover --report outputs/migrations/cutover-manifest.json
```

开启变更捕获需要清单中的授权令牌：

```powershell
python -m fangzheng_web_app.automation_migration enable-change-capture --manifest outputs/migrations/cutover-manifest.json --confirm <authorization_token>
```

该命令只开启回滚日志，不会切换应用后端。正式修改后端开关和恢复业务必须单独确认并人工执行冒烟测试。

## 回滚命令

暂停自动化写入并确认备份后，分批回放：

```powershell
python -m fangzheng_web_app.automation_migration rollback-replay --sqlite storage/app.db --backup backups/automation-cutover/automation-cutover.sqlite3 --backup-sha256 <sha256> --confirm REPLAY-POSTGRESQL-CHANGES-TO-SQLITE --batch-size 100
```

回放完成后还必须执行全量核对和业务冒烟测试，再把应用后端切回SQLite。本阶段未运行该命令。

## 观察命令

每日生成报告：

```powershell
python -m fangzheng_web_app.automation_migration observe --sqlite storage/app.db --report outputs/migrations/observation-YYYYMMDD.json
```

人工复核每日报告后执行观察门禁：

```powershell
python -m fangzheng_web_app.automation_migration observation-gate outputs/migrations/observation-*.json --minimum-days 7 --report outputs/migrations/observation-gate.json
```
